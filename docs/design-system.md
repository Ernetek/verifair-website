# VerifAir Design System

## Visual Thesis

Precise Australian enterprise SaaS with clinical calm, construction-grade practicality and a restrained operational interface.

## Typography

- Primary: Inter via Next.js font optimisation.
- Monospace: JetBrains Mono for readings, indices and telemetry labels.
- Headings use compact line-height, strong weight and zero letter spacing.

## Colour

- Ink: `#0b1220`
- Muted text: `#526070`
- Brand blue: `#0b4f6c`
- Operational green: `#17a673`
- Elevated amber: `#d58a00`
- Alert red: `#c2413b`
- Surface: `#f6f9fb`

## Components

- Header with clear navigation and primary CTA.
- Full-bleed homepage hero with supplied Dustlight visual.
- Dashboard preview with current readings, alerts, zone map and recent activity.
- Content bands, concise feature cards, comparison table, FAQ accordion and final CTA.
- Contact form with validation, privacy consent and Turnstile activation path.

## Motion

- Hero entrance sequence.
- Scroll-linked telemetry panel.
- Section reveal and hover lift transitions.
- Reduced-motion support in global CSS.
